# Mode 34900: Argon2(md5($pass))

Mode `34900` cracks Argon2 hashes whose password input is the lowercase ASCII
hexadecimal MD5 digest of the original candidate:

```text
candidate -> MD5 -> 32 lowercase hexadecimal characters -> Argon2
```

For example, `hashcat` becomes
`8743b52063cd84097a65d1633f5c74f5` before it is passed to Argon2. The recovered
plaintext and potfile entry remain the original candidate, not the intermediate
MD5 string.

The mode accepts the same PHC strings and parameters as mode `34000`, including
Argon2d, Argon2i, and Argon2id, versions 16 and 19, and the encoded memory,
iteration, parallelism, salt, and digest-length values.

## Usage

```bat
hashcat.exe -m 34900 hashes.txt wordlist.txt
hashcat.exe -m 34900 hashes.txt wordlist.txt -r rules\best64.rule
hashcat.exe -m 34900 -a 3 hashes.txt ?a?a?a?a?a?a?a?a
```

Rules, masks, hybrid attacks, and Shooter mode 13 operate on the original
candidate. The MD5 conversion occurs only after candidate generation is
complete and immediately before Argon2 initialization.

Mode `34900` specifically implements lowercase hexadecimal MD5. It does not
match constructions that pass the raw 16-byte MD5 digest or uppercase MD5 text
to Argon2; those are different algorithms.

Argon2 is intentionally memory-hard. Its PHC `m=`, `t=`, and `p=` values control
memory, iterations, and parallelism, so available GPU memory can limit the
number of simultaneous candidates. The added MD5 step is comparatively small
and does not change the Argon2 memory requirement.
